## LPIC-2 Linux Engineer

Certificación avanzada para ingenieros de sistemas Linux con capacidades empresariales.

### Exámenes

- **201-450**: Capacity Planning
- **202-450**: Linux Security

### Temas principales

**Examen 201-450:**

- Planificación de capacidad
- Kernel de Linux
- Arranque del sistema
- Sistema de archivos y dispositivos
- Administración de red avanzada
- Mantenimiento del sistema

**Examen 202-450:**

- Seguridad del sistema
- Seguridad de host
- Seguridad de red
- Criptografía
- Detección de intrusiones

### Requisitos

- Tener LPIC-1 activo
- Experiencia práctica con Linux
