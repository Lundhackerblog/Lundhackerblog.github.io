## Docker Certified Associate (DCA)

Certificación oficial de Docker para profesionales que trabajan con tecnologías de contenedores.

### Descripción

La certificación DCA valida las habilidades para usar Docker Enterprise Edition en producción.

### Contenido del examen

- Orquestación y configuración
- Gestión de imágenes
- Instalación y configuración
- Redes
- Seguridad
- Almacenamiento y volúmenes

### Dominios del examen

**Dominio 1: Orquestación (25%)**

- Docker Swarm
- Servicios y stacks
- Troubleshooting

**Dominio 2: Gestión de imágenes (20%)**

- Pull, push, tag de imágenes
- Dockerfile
- Registry management

**Dominio 3: Instalación y configuración (15%)**

- Docker Engine
- Logging drivers
- Docker daemon

**Dominio 4: Redes (15%)**

- Bridge networks
- Overlay networks
- Troubleshooting de red

**Dominio 5: Seguridad (15%)**

- RBAC
- Secrets management
- Image signing

**Dominio 6: Almacenamiento (10%)**

- Volumes
- Bind mounts
- Storage drivers

### Formato del examen

- **Duración**: 90 minutos
- **Preguntas**: 55 preguntas
- **Formato**: Opción múltiple
- **Puntuación**: 65% para aprobar
