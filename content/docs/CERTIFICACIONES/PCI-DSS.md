## PCI DSS v4.0 - Payment Card Industry Data Security Standard

Estándar de seguridad para organizaciones que manejan información de tarjetas de crédito.

### Descripción
PCI DSS v4.0 es la versión más reciente del estándar que establece requisitos de seguridad para proteger los datos de tarjetas de pago.

### Los 12 requisitos principales

**1. Firewall y configuración de routers**
- Mantener configuraciones seguras de firewall

**2. Contraseñas y parámetros de seguridad**
- No usar contraseñas por defecto

**3. Proteger datos almacenados**
- Proteger datos de tarjetas almacenados

**4. Cifrar transmisión de datos**
- Cifrar datos de tarjetas en redes públicas

**5. Usar software antivirus**
- Proteger sistemas contra malware

**6. Desarrollar sistemas seguros**
- Mantener aplicaciones y sistemas seguros

**7. Restringir acceso por necesidad**
- Limitar acceso a datos por rol empresarial

**8. Identificar y autenticar accesos**
- Asignar ID único a cada usuario

**9. Restringir acceso físico**
- Proteger acceso físico a datos de tarjetas

**10. Rastrear y monitorear accesos**
- Rastrear acceso a recursos de red y datos

**11. Probar sistemas de seguridad**
- Probar regularmente sistemas y procesos

**12. Mantener política de seguridad**
- Mantener política de seguridad de información

### Novedades en v4.0
- Autenticación multifactor obligatoria
- Cifrado mejorado
- Pruebas de penetración más frecuentes
- Gestión de vulnerabilidades automatizada

### Niveles de cumplimiento
- **Nivel 1**: +6M transacciones/año
- **Nivel 2**: 1M-6M transacciones/año
- **Nivel 3**: 20K-1M transacciones/año
- **Nivel 4**: <20K transacciones/año
